# **UNIT I – Fundamentals of Deep Learning**



Most important unit

&#x20;25 oral questions



**1. What is Deep Learning?**\
Deep Learning is a subset of Machine Learning that uses multiple layers of neural networks to learn complex patterns from data.

**2. What is the difference between Machine Learning and Deep Learning?**

- ML often requires manual feature extraction.
- DL automatically learns features using multiple neural network layers.
- DL generally requires more data and computational power.

**3. What is an Artificial Neural Network?**\
ANN is a computational model inspired by the human brain, consisting of interconnected neurons.

**4. What is a Multilayer Perceptron (MLP)?**\
MLP is a feed-forward neural network containing an input layer, one or more hidden layers and an output layer.

**5. What is a Feed Forward Neural Network?**\
It is a neural network in which information flows only from input to output without feedback connections.

**6. What is the difference between a single-layer and multilayer network?**

| Single-layer                | Multilayer                |
| --------------------------- | ------------------------- |
| No hidden layer             | One or more hidden layers |
| Simple problems             | Complex problems          |
| Limited learning capability | Learns complex patterns   |

**7. What is a Perceptron?**\
It is the basic unit of a neural network that takes inputs, applies weights and produces an output.

**8. What is Backpropagation?**\
Backpropagation calculates the error gradients from the output layer towards earlier layers and updates weights to minimize the error.

**9. What is Gradient Descent?**\
It is an optimization algorithm that minimizes the loss function by updating model parameters in the opposite direction of the gradient.

**10. What is the difference between Forward Propagation and Backpropagation?**

| Forward Propagation   | Backpropagation                  |
| --------------------- | -------------------------------- |
| Input to output       | Output error propagated backward |
| Calculates prediction | Calculates gradients             |
| Generates output      | Helps update weights             |

**11. What is the Vanishing Gradient Problem?**\
It occurs when gradients become extremely small during backpropagation, making earlier layers learn very slowly.

**12. What is the Exploding Gradient Problem?**\
It occurs when gradients become extremely large, causing unstable weight updates.

**13. What is an Activation Function?**\
It decides the output of a neuron and introduces non-linearity into a neural network.

**14. What is ReLU?**\
ReLU stands for Rectified Linear Unit. It converts negative values into zero and keeps positive values unchanged.

\\[ f(x)=\max(0,x) \\]

**15. What is Leaky ReLU (LReLU)?**\
It allows a small negative output instead of converting all negative values to zero.

\\[ f(x)=\max(0.01x,x) \\]

**16. What is ELU?**\
ELU stands for Exponential Linear Unit. It uses a smooth exponential function for negative inputs and linear output for positive inputs.

**17. Difference between ReLU, Leaky ReLU and ELU?**

| ReLU                | Leaky ReLU            | ELU                          |
| ------------------- | --------------------- | ---------------------------- |
| Negative output = 0 | Small negative output | Smooth negative output       |
| Simple              | Reduces dead neurons  | Smooth activation            |
| Fast                | Fast                  | More computationally complex |

**18. What is an Optimization Algorithm?**\
It is an algorithm used to update weights and biases to minimize the loss function.

**19. Name different optimization algorithms.**\
SGD, Momentum, RMSProp, Adagrad and Adam.

**20. What is Momentum?**\
Momentum accelerates gradient descent by using a moving average of previous gradients.

**21. What is Learning Rate?**\
It controls the size of each parameter update during training.

**22. What happens if the learning rate is too high?**\
The model may overshoot the minimum and fail to converge.

**23. What is a Hyperparameter?**\
A parameter set before training, such as learning rate, number of layers, layer size and batch size.

**24. What is Regularization?**\
Regularization is a technique used to reduce overfitting and improve model generalization.

**25. Explain Dropout, DropConnect, L1 and L2.**

- **Dropout:** Randomly disables selected neurons during training.
- **DropConnect:** Randomly disables selected connections or weights.
- **L1:** Adds the absolute values of weights to the loss.
- **L2:** Adds the squared values of weights to the loss.

### **Extra conceptual questions – Unit I**

26\. What is an Epoch? – One complete pass through the training dataset.

28\. What is an Iteration? – One parameter update using a batch of training data.

29\. What is Loss Function? – It measures the difference between predicted and actual outputs.

30\. What is Overfitting? – Model performs well on training data but poorly on unseen data.

31\. What is Underfitting? – Model fails to learn important patterns from the data.

32\. What is Generalization? – Ability of a model to perform well on unseen data.

33\. What is the purpose of hidden layers? – To learn complex features and patterns.

34\. Why do we need activation functions? – To introduce non-linearity.

35\. Can a neural network work without an activation function? – Yes, but stacked linear layers behave like a single linear transformation.

# **UNIT II – Convolutional Neural Network (CNN)**



Very important unit

&#x20;25 oral questions



**1. What is CNN?**\
CNN stands for Convolutional Neural Network. It is a deep learning architecture mainly used for processing image and spatial data.

**2. Why is CNN used for image processing?**\
It automatically extracts image features such as edges, shapes, textures and patterns.

**3. What is Convolution?**\
It is an operation in which a filter slides over an image to extract important features.

**4. What is a Filter or Kernel?**\
It is a small matrix used to detect specific features in an image.

**5. What is a Feature Map?**\
It is the output obtained after applying a convolution filter to an input image.

**6. What is Parameter Sharing?**\
Parameter sharing means using the same filter weights across different locations of an image.

**7. What is the advantage of Parameter Sharing?**\
It reduces the number of parameters and computational requirements.

**8. What is Equivariant Representation?**\
It means that when the input is transformed, the feature representation changes correspondingly. For example, shifting an image generally shifts its convolution feature map.

**9. What is Pooling?**\
Pooling is a downsampling operation used to reduce the spatial dimensions of feature maps.

**10. What are the types of Pooling?**

- Max Pooling
- Average Pooling

**11. What is Max Pooling?**\
It selects the maximum value from a particular region.

**12. What is Average Pooling?**\
It calculates the average value from a particular region.

**13. What is Stride?**\
Stride is the number of pixels by which a filter moves over an image.

**14. What is Padding?**\
Padding adds extra pixels around the image to control the output size.

**15. What are the types of Padding?**

- Same Padding
- Valid Padding

**16. What is Flattening?**\
Flattening converts multidimensional feature maps into a one-dimensional vector.

**17. What is a Fully Connected Layer?**\
It connects each neuron to all neurons in the previous layer and performs classification.

**18. Explain the basic CNN architecture.**

Input Image

Convolution Layer

ReLU Activation

Pooling Layer

Flatten Layer

Fully Connected Layer

Output / Classification

**19. What is AlexNet?**\
AlexNet is a popular deep CNN architecture that won the ImageNet Large Scale Visual Recognition Challenge in 2012.

**20. How many layers does AlexNet have?**\
It has 8 learnable layers: 5 convolutional layers and 3 fully connected layers.

**21. What is the main feature of AlexNet?**\
It uses ReLU activation, max pooling, dropout and GPU-based training.

**22. What is the difference between CNN and ANN?**\
CNN uses convolution filters and shares parameters, while a conventional fully connected ANN connects neurons densely.

**23. What is Receptive Field?**\
It is the region of the input image that influences a particular neuron in a feature map.

**24. What are Variants of the Basic Convolution Function?**\
Common variants include strided convolution, dilated convolution, transposed convolution, and locally connected convolution.

**25. What is Dilated Convolution?**\
It inserts spaces between filter elements to increase the receptive field without proportionally increasing the number of filter parameters.

26\. What is Depth in CNN? – Number of channels or feature maps.

27\. What is a Channel? – A separate component of image data, such as R, G or B.

28\. What is RGB? – Red, Green and Blue.

29\. What is Grayscale? – An image represented using shades of gray.

30\. What is Image Augmentation? – Creating modified training images using transformations such as rotation and flipping.

34\. Can CNN be used for videos? – Yes, using suitable spatial and temporal CNN architectures.

# **UNIT III – Recurrent Neural Networks (RNN)**



Important unit

&#x20;25 oral questions



**1. What is RNN?**\
RNN stands for Recurrent Neural Network. It is a neural network designed to process sequential data by maintaining information from previous steps.

**2. Why is RNN used?**\
It is used for sequential data such as text, speech, time series and video sequences.

**3. What is Sequential Data?**\
Data in which the order of elements is important.

**4. Give examples of sequential data.**\
Text, speech, stock prices, weather records and time-series data.

**5. What is the main feature of RNN?**\
It maintains a hidden state that carries information from previous time steps.

**6. What is Hidden State?**\
It is the internal memory representation that stores information from previous inputs.

**7. What is the difference between RNN and Feed Forward Neural Network?**

| FFNN                         | RNN                       |
| ---------------------------- | ------------------------- |
| No recurrent connections     | Has recurrent connections |
| No internal sequence memory  | Maintains hidden state    |
| Independent input processing | Processes sequential data |

**8. What is a Time Step?**\
A time step represents one position in a sequence processed by an RNN.

**9. What is an Unrolled RNN?**\
It is a representation of an RNN showing its repeated computation across multiple time steps.

**10. What are the types of RNN architectures?**

- One-to-One
- One-to-Many
- Many-to-One
- Many-to-Many

**11. What is One-to-Many architecture?**\
One input produces a sequence of outputs, such as image caption generation.

**12. What is Many-to-One architecture?**\
A sequence of inputs produces one output, such as sentiment classification.

**13. What is Many-to-Many architecture?**\
A sequence of inputs produces a sequence of outputs, such as machine translation.

**14. What is LSTM?**\
LSTM stands for Long Short-Term Memory. It is a special type of RNN designed to learn long-term dependencies.

**15. Why is LSTM better than a simple RNN?**\
It uses gates and a cell state to preserve important information over longer sequences.

**16. What are the three gates in LSTM?**

- Forget Gate
- Input Gate
- Output Gate

**17. What is Forget Gate?**\
It decides which information should be removed from the cell state.

**18. What is Input Gate?**\
It decides which new information should be stored.

**19. What is Output Gate?**\
It controls which information is passed as the hidden state output.

**20. What is Cell State?**\
It is the internal memory path that carries information across LSTM time steps.

**21. What is Encoder-Decoder Architecture?**\
It is a model in which an encoder converts input into a representation and a decoder generates the output sequence.

**22. What is an Encoder?**\
It processes the input sequence and creates a context representation.

**23. What is a Decoder?**\
It uses the encoded representation to generate an output sequence.

**24. What is a Recursive Neural Network?**\
It processes hierarchical structures by recursively combining representations of smaller components, such as words in a parse tree.

**25. Difference between RNN and Recursive Neural Network?**

| RNN                       | Recursive NN                 |
| ------------------------- | ---------------------------- |

# **UNIT IV – Autoencoders**



Very important unit

&#x20;25 oral questions



**1. What is an Autoencoder?**\
An Autoencoder is an unsupervised neural network that learns to compress input data and reconstruct it.

**2. What are the main components of an Autoencoder?**\
Encoder, latent representation (bottleneck) and decoder.

**3. What is an Encoder?**\
It converts input data into a compressed representation.

**4. What is a Decoder?**\
It reconstructs the original input from the compressed representation.

**5. What is a Bottleneck Layer?**\
It is the compressed middle representation of an Autoencoder.

**6. What is an Undercomplete Autoencoder?**\
It is an Autoencoder whose latent representation has fewer dimensions than the input.

**7. Why is an Undercomplete Autoencoder used?**\
To learn important features while reducing dimensionality.

**8. What is a Regularized Autoencoder?**\
It uses additional constraints or penalties to prevent the network from simply copying the input.

**9. What is a Sparse Autoencoder?**\
It encourages only a small number of neurons to be active at a time.

**10. What is Sparsity?**\
Sparsity means that most neuron activations are zero or close to zero.

**11. What is a Stochastic Encoder?**\
It produces a probability distribution or samples a latent representation instead of always producing a fixed representation.

**12. What is a Stochastic Decoder?**\
It models a probability distribution over reconstructed outputs.

**13. What is a Denoising Autoencoder?**\
It learns to reconstruct clean data from corrupted or noisy input.

**14. How does a Denoising Autoencoder work?**\
Noise is added to input data, and the model is trained to reconstruct the original clean data.

**15. What is a Contractive Autoencoder?**\
It is an Autoencoder that penalizes sensitivity of the learned representation to small input changes.

**16. What is the purpose of a Contractive Autoencoder?**\
To learn robust representations that are less sensitive to small variations in input.

**17. What is Reconstruction Error?**\
It is the difference between the original input and reconstructed output.

**18. Which loss functions are used in Autoencoders?**\
Mean Squared Error and Binary Cross-Entropy are commonly used.

**19. What is Latent Space?**\
It is the compressed feature space learned by the encoder.

**20. What is the difference between Encoder and Decoder?**

| Encoder               | Decoder                  |
| --------------------- | ------------------------ |
| Compresses data       | Reconstructs data        |
| Input to latent space | Latent space to output   |
| Extracts features     | Generates reconstruction |

**21. What is a Variational Autoencoder (VAE)?**\
VAE is a generative model that learns a probability distribution in latent space and can generate new samples.

**22. Difference between a normal Autoencoder and VAE?**

| Normal Autoencoder               | VAE                             |
| -------------------------------- | ------------------------------- |
| Learns compressed representation | Learns probability distribution |
| Mainly reconstructs input        | Can generate new data           |
| Deterministic encoding is common | Probabilistic encoding          |

**23. What is Anomaly Detection using Autoencoders?**\
It detects abnormal data by identifying samples with high reconstruction error.

**24. What are the applications of Autoencoders?**\
Data compression, image denoising, anomaly detection, feature extraction and dimensionality reduction.

**25. Can an Autoencoder work without labeled data?**\
Yes. It generally learns from input data by reconstructing it, without requiring class labels.

### **Extra conceptual questions – Unit IV**

26\. What is an Anomaly? – An unusual pattern that differs from normal data.

27\. What is an Anomaly Score? – A numerical measure indicating how unusual a sample is.

28\. What is Thresholding? – Using a selected threshold to classify samples based on reconstruction error.

29\. What happens if the bottleneck is too large? – The model may learn to copy inputs without learning useful compressed features.

30\. What is Feature Learning? – Automatically learning useful representations from raw data.

31\. Can Autoencoders be used for image restoration? – Yes, they can reconstruct damaged or noisy images.

32\. What is Regularization Loss? – An additional penalty added to the reconstruction loss to encourage desired model properties.

33\. What is the difference between Denoising and Contractive Autoencoders? – Denoising learns reconstruction from corrupted input; Contractive penalizes sensitivity to small input changes.

34\. What is the main objective of an Autoencoder? – To learn useful compressed representations and reconstruct input.

35\. Give a real-life example of an Autoencoder. – Detecting unusual transactions or network activity.

# **UNIT V – Representation Learning**



Important unit

&#x20;25 oral questions



**1. What is Representation Learning?**\
It is a technique in which a model automatically learns useful features or representations from raw data.

**2. Why is Representation Learning important?**\
It reduces manual feature engineering and helps models understand complex data.

**3. What is Feature Learning?**\
It is the automatic extraction of meaningful features from input data.

**4. What is Distributed Representation?**\
It represents information using multiple values or neurons rather than a single individual feature.

**5. Give an example of Distributed Representation.**\
Word embeddings, where a word is represented by a numerical vector.

**6. What is Greedy Layerwise Pre-training?**\
It is a training approach in which neural network layers are trained one at a time, starting from the first layer.

**7. Why is Greedy Layerwise Pre-training used?**\
It helps initialize deep neural networks with useful representations before complete network training.

**8. How does Greedy Layerwise Pre-training work?**

- Train the first layer using input data.
- Use its output as input to the next layer.
- Train each subsequent layer.
- Fine-tune the complete network.

**9. What is Pre-training?**\
It is the process of training a model on data before training it for a specific target task.

**10. What is Transfer Learning?**\
It reuses knowledge from a previously trained model for a new but related task.

**11. Why is Transfer Learning used?**\
It saves time, reduces computational requirements and helps when training data is limited.

**12. What is a Pre-trained Model?**\
A model that has already learned features from a large dataset.

**13. Give examples of pre-trained models.**\
VGG16, ResNet, MobileNet, DenseNet and Inception.

**14. What is Fine-Tuning?**\
It is the process of further training selected layers of a pre-trained model on a new dataset.

**15. What is Feature Extraction in Transfer Learning?**\
It uses the learned features of a pre-trained model while keeping its weights fixed.

**16. Difference between Feature Extraction and Fine-Tuning?**

| Feature Extraction               | Fine-Tuning                 |
| -------------------------------- | --------------------------- |
| Pre-trained layers remain frozen | Some layers are unfrozen    |
| Uses existing features           | Adapts features to new data |
| Less training required           | More training required      |

**17. What is Domain Adaptation?**\
It is a technique that adapts a model trained in one data domain to work effectively in another domain.

**18. What is Source Domain?**\
The original domain from which training data is obtained.

**19. What is Target Domain?**\
The new domain where the model needs to perform.

**20. What is Domain Shift?**\
It occurs when the data distribution in the training domain differs from that in the target domain.

**21. What is DenseNet?**\
DenseNet stands for Densely Connected Convolutional Network. It is a CNN architecture in which each layer receives feature maps from all preceding layers in a dense block.

**22. What is Dense Connectivity?**\
It means each layer is connected to all earlier layers within the same dense block.

**23. What is the advantage of DenseNet?**\
It encourages feature reuse, improves gradient flow and can reduce the number of parameters compared with some conventional architectures.

**24. Difference between ResNet and DenseNet?**

| ResNet                    | DenseNet                              |
| ------------------------- | ------------------------------------- |
| Uses residual connections | Uses dense connections                |
| Adds previous features    | Concatenates previous features        |
| Shortcut connections      | All-to-all connections within a block |

**25. What are the applications of Representation Learning?**\
Image recognition, NLP, speech recognition, recommendation systems and transfer learning.

### **Extra conceptual questions – Unit V**

26\. What is a Feature Vector? – A numerical representation of input features.

27\. What is Embedding? – Mapping data into a lower-dimensional numerical vector space.

28\. What is General Feature Extraction? – Identifying useful patterns from raw data.

29\. What is Knowledge Transfer? – Reusing learned information from one task for another.

30\. What is Domain Generalization? – Training models to perform well across different domains.

31\. What is a Dense Block in DenseNet? – A group of layers where each layer receives feature maps from all preceding layers.

32\. What is Transition Layer in DenseNet? – A layer used to reduce feature map dimensions between dense blocks.

33\. What is the role of 1×1 convolution in DenseNet? – It helps reduce the number of channels and computational cost.

34\. What is Global Average Pooling? – It calculates the average of each feature map to produce a compact feature vector.

35\. What is the main difference between traditional feature extraction and representation learning? – Traditional methods often use manually designed features; representation learning learns features automatically.
