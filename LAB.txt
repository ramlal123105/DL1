**Theory:**

Deep Learning is a subfield of Machine Learning that uses artificial neural networks to learn patterns and features from large amounts of data. It is inspired by the working of the human brain, where interconnected neurons process information and produce results.

Deep learning models contain multiple layers of artificial neurons. These layers process input data, extract useful features and generate predictions. Deep learning is widely used in image recognition, speech recognition, natural language processing, medical diagnosis and autonomous vehicles.

Several frameworks and libraries are available to develop deep learning applications.

**1. TensorFlow:**

- TensorFlow is an open-source deep learning framework developed by Google.
- It is used to create, train and deploy machine learning models.
- It supports CPU and GPU processing.
- It provides tools for building neural networks and performing mathematical operations.
- It is widely used in image classification and speech recognition.

**2. Keras:**

- Keras is a high-level deep learning API.
- It provides a simple and user-friendly interface for creating neural networks.
- It supports layers, optimizers, loss functions and activation functions.
- It works with TensorFlow as its backend.
- It is useful for rapid development and experimentation.

**3. Theano:**

- Theano is a Python library used for numerical and mathematical computations.
- It allows users to define and optimize mathematical expressions.
- It supports automatic differentiation.
- It can perform computations using GPUs.
- It was historically used for developing deep learning models.

**4. PyTorch:**

- PyTorch is an open-source deep learning framework developed by Meta.
- It uses tensors for mathematical operations.
- It supports dynamic computation graphs.
- It provides automatic differentiation through Autograd.
- It is widely used in research and deep learning applications.

These frameworks simplify the development, training and testing of deep learning models.

## **Practical 2: Implementation of Feed Forward Neural Network**

**Aim:** To implement a Feed Forward Neural Network using Keras and TensorFlow on the MNIST dataset.

**Objectives:**

1. To understand the architecture of an Artificial Neural Network.
2. To study the working of a Feed Forward Neural Network.
3. To implement input, hidden and output layers.
4. To train the neural network using the MNIST dataset.
5. To evaluate the model using accuracy and loss.

**Theory:**

A Feed Forward Neural Network (FFNN) is one of the simplest types of artificial neural networks. In this network, information flows in only one direction, from the input layer through hidden layers to the output layer. There are no feedback connections or loops.

A neural network consists of interconnected artificial neurons. Each neuron receives input values, multiplies them by weights, adds a bias and applies an activation function to produce an output.

**Architecture of Feed Forward Neural Network:**

The network consists of three main layers:

**1. Input Layer:**

- It is the first layer of the neural network.
- It receives input data from the dataset.
- Each neuron represents an input feature.
- It passes the input values to the hidden layer.

**2. Hidden Layer:**

- It is present between the input and output layers.
- It performs calculations using weights and biases.
- It extracts useful patterns from the input data.
- Activation functions such as ReLU are used to introduce non-linearity.

**3. Output Layer:**

- It is the final layer of the network.
- It generates the predicted result.
- The number of neurons depends on the number of output classes.
- Softmax is commonly used for multi-class classification.

**Working of Feed Forward Neural Network:**

1. Input data is supplied to the input layer.
2. The input values are multiplied by their corresponding weights.
3. Bias values are added to the weighted sum.
4. An activation function is applied to generate the output of each neuron.
5. The result is passed forward to the next layer.
6. The output layer generates the final prediction.
7. The predicted output is compared with the actual output using a loss function.
8. Backpropagation calculates the error gradients.
9. The optimizer updates weights and biases to reduce the error.
10. This process repeats for multiple epochs until the model learns properly.

**MNIST Dataset:**

MNIST is a popular dataset used for handwritten digit recognition. It contains 70,000 grayscale images of handwritten digits from 0 to 9. Each image has a size of 28 × 28 pixels. It is divided into training and testing datasets.

Keras and TensorFlow are used to build and train the neural network on this dataset.

## **Practical 3: Image Classification using Convolutional Neural Network (CNN)**

**Aim:** To implement an image classification model using Convolutional Neural Network (CNN).

**Objectives:**

1. To understand the concept and architecture of CNN.
2. To study different layers used in CNN.
3. To extract important features from images.
4. To classify images into different categories.
5. To evaluate the performance of the CNN model.

**Theory:**

Convolutional Neural Network (CNN) is a type of deep learning neural network mainly used for image processing and computer vision applications. It automatically learns important features from images without requiring manual feature extraction.

CNN processes images in the form of pixel values. It identifies patterns such as edges, lines, shapes, textures and objects. These features are used to classify images into different categories.

CNN consists of multiple layers that perform different operations.

**Main Layers of CNN:**

**1. Convolution Layer:**

- It is the main layer of CNN.
- It applies filters or kernels to the input image.
- It extracts important features such as edges, corners and patterns.
- The output generated is called a feature map.

**2. ReLU Activation Layer:**

- ReLU stands for Rectified Linear Unit.
- It introduces non-linearity into the network.
- It converts negative values into zero.
- It helps the network learn complex patterns.

**3. Pooling Layer:**

- It reduces the dimensions of feature maps.
- It decreases computational complexity.
- Max Pooling selects the maximum value from a region.
- Average Pooling calculates the average value of a region.

**4. Flatten Layer:**

- It converts the multidimensional feature maps into a one-dimensional vector.
- This vector is passed to the fully connected layer.

**5. Fully Connected Layer:**

- It connects all neurons from the previous layer.
- It uses extracted features for classification.
- It helps determine the category of the input image.

**6. Output Layer:**

- It produces the final classification result.
- Softmax activation is commonly used for multiple classes.
- It provides the probability of each class.

**Working of CNN:**

1. An image is given as input to the CNN model.
2. The convolution layer extracts features using filters.
3. The ReLU layer applies activation.
4. The pooling layer reduces the feature map size.
5. The flatten layer converts features into a vector.
6. Fully connected layers perform classification.
7. The output layer predicts the image category.
8. The model is trained using a dataset and optimized by reducing the loss.

CNN is widely used in face recognition, object detection, medical image processing, handwritten digit recognition and autonomous vehicles.

## **Practical 4: Anomaly Detection using Autoencoder**

**Aim:** To implement anomaly detection using an Autoencoder.

**Objectives:**

1. To understand the concept and architecture of Autoencoders.
2. To study encoding and decoding processes.
3. To learn data compression and reconstruction.
4. To detect abnormal patterns in datasets.
5. To identify anomalies using reconstruction error.

**Theory:**

An Autoencoder is a type of artificial neural network mainly used for unsupervised learning. It learns to represent input data in a compressed form and reconstruct the original data from that representation.

Autoencoders are trained to reproduce their input as accurately as possible. They learn the important features and patterns present in the training data.

An Autoencoder consists of three main components:

**1. Encoder:**

- It is the first part of an Autoencoder.
- It receives the original input data.
- It converts the input into a smaller and compressed representation.
- It extracts important features from the input.

**2. Bottleneck Layer:**

- It is the middle layer of the Autoencoder.
- It stores the compressed representation of the input.
- It contains the most important information required for reconstruction.
- It prevents the model from simply copying the input directly.

**3. Decoder:**

- It receives the compressed representation from the bottleneck layer.
- It reconstructs the original input data.
- It tries to generate an output as close as possible to the original input.

**Working of Autoencoder:**

1. Input data is provided to the encoder.
2. The encoder compresses the input into a smaller representation.
3. The compressed data is passed to the bottleneck layer.
4. The decoder uses this representation to reconstruct the input.
5. The reconstructed output is compared with the original input.
6. The difference between original and reconstructed data is calculated.
7. This difference is called reconstruction error.
8. The model is trained to minimize reconstruction error.

**Anomaly Detection using Autoencoder:**

Anomaly detection is the process of identifying unusual or abnormal data that differs from normal patterns.

- The Autoencoder is trained mainly using normal data.
- It learns the common patterns of normal data.
- When normal data is provided, it reconstructs it with low error.
- When unusual data is provided, it may produce a higher reconstruction error.
- A threshold value is selected to identify anomalies.
- If reconstruction error is greater than the threshold, the data is classified as anomalous.

Autoencoders are used in fraud detection, network intrusion detection, equipment fault detection, medical diagnosis and industrial monitoring.

## **Practical 5: Implementation of Continuous Bag of Words (CBOW)**

**Aim:** To implement the Continuous Bag of Words (CBOW) model for word prediction.

**Objectives:**

1. To understand Natural Language Processing (NLP).
2. To study the Word2Vec model and its architecture.
3. To understand the working of Continuous Bag of Words.
4. To predict a target word using surrounding context words.
5. To learn the concept of word embeddings.

**Theory:**

Natural Language Processing (NLP) is a branch of Artificial Intelligence that enables computers to understand, process and interpret human languages.

Computers cannot directly understand text in the same way humans do. Therefore, words are converted into numerical representations that can be processed by machine learning algorithms.

Word2Vec is a technique used to convert words into numerical vectors called word embeddings. These vectors represent the meaning and relationships between words.

Continuous Bag of Words (CBOW) is one of the two main architectures of Word2Vec. The other architecture is Skip-Gram.

**Continuous Bag of Words (CBOW):**

CBOW is a neural network-based model that predicts a target word using its surrounding context words.

For example:

Sentence: "The cat is sitting on the mat."

If the target word is "sitting", the surrounding words such as "cat", "is", "on" and "the" can be used as context to predict it.

**Architecture of CBOW:**

**1. Input Layer:**

- It receives the surrounding context words.
- The words are converted into numerical representations.
- These representations are provided to the network.

**2. Hidden Layer:**

- It processes the input word vectors.
- It combines the context information.
- It generates a common representation of the surrounding words.

**3. Output Layer:**

- It predicts the target word.
- It calculates the probability of possible vocabulary words.
- The word with the highest probability is selected as the predicted word.

**Working of CBOW:**

1. A sentence is selected as input.
2. The target word is selected from the sentence.
3. Surrounding words are taken as context words.
4. Context words are converted into word vectors.
5. The vectors are combined to generate a context representation.
6. The hidden layer processes this representation.
7. The output layer predicts the target word.
8. The predicted word is compared with the actual target word.
9. Model weights are updated to improve prediction accuracy.

**Applications of CBOW:**

- Text classification.
- Sentiment analysis.
- Search engines.
- Language translation.
- Document similarity.
- Information retrieval.

## **Practical 6: Object Detection using Transfer Learning**

**Aim:** To implement object detection using Transfer Learning of CNN architectures.

**Objectives:**

1. To understand the concept of Transfer Learning.
2. To study pre-trained CNN architectures.
3. To reuse previously trained models for new tasks.
4. To detect and classify objects in images.
5. To understand the use of bounding boxes and confidence scores.

**Theory:**

Transfer Learning is a Machine Learning technique in which knowledge gained by a model while solving one problem is reused to solve another related problem.

Training a deep learning model from scratch requires a large amount of data, computational resources and time. Transfer Learning reduces these requirements by using an already trained model.

A pre-trained model is a model that has already been trained on a large dataset such as ImageNet. It has learned basic image features like edges, shapes, textures and patterns.

**Transfer Learning using CNN:**

CNN architectures are commonly used for Transfer Learning because they can automatically extract useful image features.

Some popular pre-trained CNN architectures are:

**1. VGG16:**

- It is a deep CNN architecture.
- It consists of 16 weight layers.
- It uses small 3 × 3 convolution filters.
- It is commonly used for image classification and feature extraction.

**2. ResNet:**

- ResNet stands for Residual Network.
- It uses shortcut connections between layers.
- It helps train very deep neural networks.
- It is useful for image recognition tasks.

**3. MobileNet:**

- It is a lightweight CNN architecture.
- It is designed for mobile and embedded devices.
- It requires less computational power.
- It is useful for real-time image applications.

**Object Detection:**

Object Detection is a computer vision technique used to identify objects and determine their positions in an image.

It performs two main tasks:

1. **Object Classification:** Identifies which objects are present in an image.
2. **Object Localization:** Determines the position of each object using bounding boxes.

**Important Terms in Object Detection:**

- **Bounding Box:** A rectangular box used to indicate the location of an object.
- **Class Label:** The name or category assigned to a detected object.
- **Confidence Score:** Indicates how confident the model is about its prediction.
- **IoU (Intersection over Union):** Measures the overlap between predicted and actual bounding boxes.

**Working of Transfer Learning:**

1. A pre-trained CNN model is selected.
2. The pre-trained model is loaded with its learned weights.
3. The original classification layer may be replaced with a new task-specific layer.
4. A new dataset is provided to the model.
5. The model extracts features from the input images.
6. The detection or classification layers predict the objects.
7. The model is fine-tuned using the new dataset.
8. The final model is tested on new images.
9. Detected objects are displayed using bounding boxes and labels.

Transfer Learning is widely used in surveillance systems, traffic monitoring, face recognition, medical imaging, robotics and self-driving cars.
